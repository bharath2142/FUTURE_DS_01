# 📊 E-Commerce Sales Analysis Dashboard

## 📌 Project Overview

This project analyzes an e-commerce sales dataset using **Python** for data cleaning and exploratory data analysis (EDA) and **Power BI** for creating an interactive business dashboard.

The objective is to identify sales trends, top-performing products, customer insights, and country-wise revenue to support business decision-making.

---

## 🎯 Objectives

- Clean and preprocess raw sales data
- Perform Exploratory Data Analysis (EDA)
- Calculate key business KPIs
- Visualize sales trends
- Build an interactive Power BI dashboard
- Generate actionable business insights

## 💡 Key Insights

- The business generated approximately **8.89M** in total revenue.
- Around **19K** completed orders were processed.
- The dataset contains **4,338** unique customers.
- Sales reached their highest level in **November**.
- The **United Kingdom** generated the highest revenue.
- A small number of products contributed significantly to total sales.
